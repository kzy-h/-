# 瞌睡米塔桌宠增强版

## 0.5.7 点击修复、角色包自检与动作测试

- 重新校准 2:3 全身立绘的脸、头发、身体命中范围，胸口、肩膀和手臂不再误判为头发。
- 连续点击只在同一部位内累计；脸部与身体使用各自的动作池，头发保留三级摸头反应。
- 点击立绘只触发互动动作，不再顺带推进对白，避免动作刚出现就被说话状态顶掉。
- 旧版瞌睡米塔角色目录即使已有基础头像，也会为缺失的新增动作自动补查增强版内置素材。
- 桌宠设置新增角色包自检：检查基础立绘、全部动作素材、缺失列表与内置素材回退数量。
- 桌宠设置新增动作测试面板，可逐张触发动作，缺失素材会在完成自检后自动禁用。
- 拖动持续立绘、说话时拖动不换动作、音乐动作恢复和既有动作优先级保持不变。

## 0.5.6 交互增强第三版

- 所有动作统一登记在动作清单中，集中声明素材、优先级、最短展示时间、冷却、轻微动态和恢复策略。
- 新增统一优先级调度器：拖动不会被点击打断；点击暂时打断听歌后，音乐仍在播放时可恢复耳机动作。
- 加入两张头发专属立绘。十秒内连续摸头会从护住眼罩、侧目逐步升级为抱臂抗议。
- 动作立绘会预加载并平滑淡入淡出；可为静态立绘添加轻呼吸、摇摆、犯困和轻弹等细微动态。
- 新增早晨、中午、夜晚、深夜四个时段的陪伴动作，每次运行中每个时段最多主动出现一次。
- 桌宠设置新增平滑切换、轻微动态、分时段陪伴和动作调试信息四个开关。
- 调试信息可显示命中区域、连续点击次数、当前动作、优先级，以及动作被接受或拦截的原因。
- 语音链路保持不变；角色说话时仍优先保留对话立绘与音频，拖动不会中断说话。

## 0.5.5 交互增强第二版

- 点击立绘的脸、头发和身体会使用不同的动作池，连续点击会逐步切换为侧目、叉腰或鼓脸抗议。
- 同一动作增加冷却时间，待机动作采用带权随机并避开近期重复，减少立绘频繁闪烁。
- 桌宠设置页新增点击互动、随机待机、音乐动作、说话时保持立绘四个开关。
- 动作频率可选低、适中、高，控制待机动作和音乐动作的触发间隔。
- 所有新设置都会持久化，并通过桌宠设置窗口即时同步到桌宠。

## 0.5.4 交互状态增强

- 角色说话时拖动窗口不再切换成慌张立绘，当前语音和对话情绪会继续保持。
- 非说话状态的拖动动作会持续到 Windows 检测到鼠标真正松开，不再固定约一秒结束。
- “戴耳机听歌”改为跟随背景音乐的播放、暂停与停止状态，并避免在说话时触发。
- 单击会在鼓脸、扶眼罩侧目、叉腰吐槽、害羞扭头之间轮换；双击会在敲屏幕与开心挥手之间轮换。
- AI 思考期间会显示托下巴思考动作；说话开始后仍由对话情绪立绘接管。

## 0.5.3 立绘显示修复

- 安装包直接内置瞌睡米塔完整角色素材，不再要求先手动导入角色包。
- 兼容旧角色包文件名产生的 `resource_folder`，旧存档会自动回退到内置素材。
- Windows 立绘优先通过后端读取为 data URL，避免本地 asset 协议异常时只显示空白。
- 升级安装时会补齐缺失素材，但不会覆盖用户已经修改过的同名文件。

此分支把 LingChat 的静态桌宠从圆形头像改为透明全身立绘，并为角色包的
`extra_actions` 素材增加交互状态机。

## 已接入的触发方式

| 触发     | 动作                                             |
| -------- | ------------------------------------------------ |
| 单击角色 | 按脸、头发、身体区域触发不同动作，不推进当前对白 |
| 连续点击 | 逐步触发侧目、叉腰和鼓脸抗议                     |
| 双击角色 | 敲屏幕或开心挥手                                 |
| 拖动窗口 | 慌张张手                                         |
| 久坐提醒 | 递咖啡提醒休息                                   |
| 白天空闲 | 打哈欠、坐屏幕边缘、探头、偷吃饼干随机切换       |
| 深夜空闲 | 打哈欠、趴桌睡、抱枕、戴眼罩、裹毯子随机切换     |
| AI 对话  | 没有临时动作时，继续使用角色当前情绪立绘         |

动作优先级为：拖动 > 久坐提醒 > 点击/双击 > 空闲 > 对话情绪。高优先级动作期间，
低优先级动作不会把它顶掉。动作文件不存在时会自动回退到当前情绪立绘。

## 角色包要求

角色目录保持 LingChat 原结构，并可额外放置：

```text
角色目录/
├─ settings.yml
├─ avatar/
│  ├─ 正常.png
│  ├─ 慌张.png
│  └─ 其他情绪.png
└─ extra_actions/
   ├─ 01_打哈欠和伸懒腰.png
   ├─ 20_坐在屏幕边缘晃腿.png
   └─ ...
```

瞌睡米塔增强版已内置动作素材并符合该结构，无需把原来的情绪立绘删除或另行合并。

## 独立运行与构建

增强版使用独立应用标识 `com.kzyh.sleepymita.lingchat`，可与官方 LingChat 共存，
并关闭官方应用覆盖更新。数据资源同步仍保留。

```powershell
pnpm install
pnpm tauri:mita:dev
pnpm tauri:mita:build
```

Windows 安装包会生成到 `src-tauri/target/release/bundle/nsis/`。

如果本机没有 Rust/Tauri 环境，可在 GitHub 仓库的 Actions 页面手动运行
“构建瞌睡米塔增强版（Windows）”，完成后下载
`sleepy-mita-lingchat-enhanced-windows` 构建产物即可。
